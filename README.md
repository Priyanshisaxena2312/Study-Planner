# Studywell — Smart Study Planner UI

A free, responsive React UI starter for a Smart Study Planner using a sage-green and off-white visual system.

## Features in this UI milestone
- Responsive dashboard layout with sidebar navigation
- Study overview cards and weekly activity chart
- Today's study plan with interactive task completion
- Add-study-session modal
- Subject progress cards
- Sample AI insight and upcoming exam card
- Sage-green and off-white visual theme

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite (usually http://localhost:5173).

## Tech stack
- React + Vite
- CSS
- Lucide React
- Recharts

## Important
This first milestone is frontend-only. The displayed student, exam, chart, and recommendation information is sample data. No paid API or ML model is connected. Future phases can add your own backend and models trained by you.
